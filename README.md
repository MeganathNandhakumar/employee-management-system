# Employee Management System

A Python-based Employee Management System that allows users to manage employee records through a simple command-line interface.

## Features

- Add new employees
- Display all employees
- Search for employees
- Update employee information
- Delete employees
- Input validation
- Automatic employee ID generation
- Store employee data in a JSON file

## Technologies Used

- Python
- JSON
- Object-oriented programming
- File handling
- Input validation
